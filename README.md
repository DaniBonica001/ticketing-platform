# Ticketing Platform

Reactive, event-driven ticketing backend (Java 25, Spring Boot 4, WebFlux, DynamoDB, SQS) built with the
[Bancolombia Clean Architecture scaffold](https://bancolombia.github.io/scaffold-clean-architecture/).

> Work in progress. Full documentation (architecture, setup, endpoints, limitations, improvements and
> production considerations) will be added as the implementation progresses.

Infrastructure as Code lives in [ticketing-infra](https://github.com/DaniBonica001/ticketing-infra).
